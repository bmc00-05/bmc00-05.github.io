원자적 트랜잭션(transaction.atomic)

데이터베이스 작업을 하나의 원자적 단위로 묶어, 성공적으로 완료되면 커밋되고 실패하면 롤백되도록 보장하는 패턴. 중간에 실패가 발생하더라도 모든 변경분이 반영되지 않도록 함으로써 데이터 불일치를 제거한다.

## Topic 3: 신규 배지 노출과 UX를 위한 알림 설계
> 문제 정의: 사용자가 새로운 배지를 어떻게 인식하고 확인하는지에 대한 UX 고민을 서술합니다.
> 탐색: new_badges payload, announced_at 플래그, ack 엔드포인트의 역할을 검토합니다.
> 해결: 프런트-백엔드 간의 인터랙션 흐름과 데이터 모델상의 결정 요약합니다.
> 인사이트: 알림 설계에서의 사용성 개선 포인트와 확장 아이디어를 기록합니다.

from rest_framework.decorators import api_view, permission_classes
from rest_framework.permissions import IsAuthenticated
from rest_framework.response import Response

@api_view(['GET'])
@permission_classes([IsAuthenticated])
def new_badges_payload(request):
    profile = Profile.objects.get(user=request.user)
    qs = UserBadge.objects.filter(profile=profile, announced_at__isnull=True).select_related('badge').order_by('earned_at')
    payload = [
        {
            'id': ub.badge.id,
            'code': ub.badge.code,
            'name': ub.badge.name,
            'description': ub.badge.description,
            'icon': ub.badge.icon,
            'earned_at': ub.earned_at.isoformat(),
        } for ub in qs
    ]
    return Response({'new_badges': payload})
